# Real-time Network Anomaly Detection

A full-stack anomaly detection system for network intrusion detection using ML ensemble methods and LLM-powered explanations.

## Features
- Real-time WebSocket-based live dashboard
- Ensemble anomaly detectors (Z-Score, IQR, Threshold, Modified Z-Score)
- LLM-generated root cause explanations via OpenRouter
- CIC-IDS-2017 network flow schema support
